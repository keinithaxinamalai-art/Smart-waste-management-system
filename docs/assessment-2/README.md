# Assessment 2 — what to put on Moodle

One member uploads one Word report. Attach the CIHE cover sheet. Paste the **Jira URL** on the cover and on the first page of the report (it is still a placeholder).

## Files in this folder

| File | Use |
|---|---|
| `ASSESSMENT-2-TECHNICAL-REPORT.md` / `.docx` | ~4000-word group report (Calibri 12 in Word) |
| `USER-GUIDE.md` / `.docx` | Appendix — install, accounts, click path |
| `UAT-CHECKLIST.md` | Print or screenshot the twelve ticks after rehearsal |
| `WEEK-11-DEMO.md` | 15-minute split (10 demo + 5 questions) |

Root copies for a quick ZIP: `ICT308-Assessment-2-Technical-Report.docx` and `ICT308-Assessment-2-User-Guide.docx`.

## Before upload

1. Paste the live Jira link.
2. Export one Jira board screenshot (To Do / In Progress / Done).
3. On the demonstration laptop, take screenshots named in the user guide and paste them into the Word user guide.
4. Run `npm test` (22 passing) and keep a terminal screenshot.
5. Confirm GitHub is visible to the teaching team: https://github.com/keinithaxinamalai-art/Smart-waste-management-system

Assessment 1 report stays in `docs/ITERATION-1-REPORT.md`. Assessment 3 poster and reflections are in `docs/assessment-3/`.
