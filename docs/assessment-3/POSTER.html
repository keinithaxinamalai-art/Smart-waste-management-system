Canberra SmartWaste

A smart waste monitoring and citizen reporting prototype for the ACT

Simulated TCCS / Canberra pilot — not live IoT hardware

Problem

Fixed collection days send trucks to empty bins and still leave busy public bins overflowing. Fuel is wasted and streets get dirty.

Solution

A role-based software prototype. Simulated Canberra bin fill data, a rule-based pickup score, and a citizen report form with WST-2026-XXXX tracking. No black-box A.I. routing.

System overview

Citizen — report overflow / damage, track status (Submitted → Under Review → Scheduled → Resolved).

Collection staff — only bins ≥80% full are on the run. Empty bins are skipped. Mark Collected resets fill to 5%.

Administrator — dashboard, map, alerts, assign Route ACT-R104, maintenance tickets, reset demo data.

One shared state (AppContext). Persistence is browser localStorage in dataStore.ts — there is no cloud SQL database in this delivery.

Implementation highlights

FillStatus
0–49%Normal — skip truck
50–79%Moderate — skip truck
80–89%Collection required
90–100%Critical — go first if score is highest

Priority score = fill×0.5 + urgency + overdue time. Collection closes only reports with the same bin ID.
